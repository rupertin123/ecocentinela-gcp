Conceptual project: no physical nodes or customers. Sensor data are generated every 15 min by a simulated fleet of 12 nodes in fictitious greenhouses, using Río Cuarto climate normals (SMN 1991–2020) and greenhouse-whitefly development parameters (Greenberg et al., 2000). Values marked as estimates depend on assumptions that a field pilot would calibrate.

Hardware specs (reference design)

Optical nodeESP32-CAM (OV2640) imaging a yellow sticky trap; FOMO (TinyML) counts adult whiteflies on-device
RadioLoRa SX1276 module, AU915-928 plan (ENACOM Res. 551/2021 & 280/2022), sub-band 2
Data rateDR2 (SF10 / 125 kHz) — max 11 B with 400 ms dwell time (LoRaWAN RP002-1.0.3, table 45)
Payload10 bytes binary (original JSON: 54–70 bytes, did not fit)
Uplink period15 min
PowerSolar panel + Li-ion cell
Gateway8-channel LoRaWAN gateway + ChirpStack v4 (HTTP integration → Cloud Run)
CloudCloud Run · Pub/Sub · BigQuery (+ BigQuery ML ARIMA_PLUS) · Firestore · Cloud Scheduler · Terraform
