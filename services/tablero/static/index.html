Conceptual project: no physical nodes or customers. Data are generated every hour (7–20 h, cameras need daylight) by a simulated fleet of 12 nodes in a fictitious soybean field, using Río Cuarto climate normals (SMN 1991–2020). The season clock replays V6→R7 every 90 days so the demo always shows decision-relevant stages. Thresholds and efficacy priors come from INTA and UNRC publications; values marked as estimates depend on assumptions that a field pilot would calibrate. The system recommends; the grower and their agronomist decide.

Hardware specs (reference design)

Optical nodeESP32-CAM (OV2640) photographing the canopy; FOMO (TinyML) counts the target pest on-device — the photo never leaves the node
Layout4 masts × 3 nodes: 75 cm (oruga medidora, Rachiplusia nu), 45 cm (chinche de la alfalfa, Piezodorus guildinii), 15 cm macro on a lower leaflet (trips, Caliothrips phaseoli). Heights are adjustable as the crop grows.
RadioLoRa SX1276 module, AU915-928 plan (ENACOM Res. 551/2021 & 280/2022), sub-band 2
Data rateDR2 (SF10 / 125 kHz) — max 11 B with 400 ms dwell time (LoRaWAN RP002-1.0.3, table 45)
Payload10 bytes binary: count, confidence, temperature, relative humidity, battery, 4×4 occupancy map
SamplingOne photo per hour from 07:00 to 20:00 (no IR: no night photos)
PowerSolar panel + Li-ion cell, deep sleep at night
Gateway8-channel LoRaWAN gateway + ChirpStack v4 (HTTP integration → Cloud Run)
CloudCloud Run · Pub/Sub · BigQuery (+ BigQuery ML ARIMA_PLUS, residual-efficacy regression) · Firestore · Cloud Scheduler · Secret Manager · Terraform
